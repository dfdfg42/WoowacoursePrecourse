# woowacourse-precourse

우아한테크코스 프리코스 미션 모음. 흩어져 있던 fork를 하나로 모은 모노레포다.

- 미션별 폴더는 독립 Gradle 프로젝트다. IntelliJ에서 폴더 단위로 연다.
- 본인 풀이가 있는 미션은 커밋 히스토리를 그대로 가져왔다. `git log -- <폴더>` 또는 GitHub 폴더 History로 볼 수 있다.
- 템플릿만 있는 미션은 우테코 원본 파일을 복사한 것이고 히스토리가 없다.
- 통합 과정은 [docs/2026-09-16-precourse-monorepo-design.md](docs/2026-09-16-precourse-monorepo-design.md) 참고.
