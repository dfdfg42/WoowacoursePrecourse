# 페어 매칭

## 크루 객체 생성
 -[x] 과정  이름

## 크루 객체 데이터 입력
 -[x] datainitializer 파일 입출력으로 크루 목록 생성

## 페어 객체 생성
 -[x] 과목 학생 A B

## 미션 객체 생성
 -[x] 미션 객체 생성 ( 미션 은  과목 레벨,페어 객체로 구성)
 -[x] 미션 저장소 생성 
 -[x] 미션 초기화 

## 기능 선택 입력
 - [ ] 기능선택 목록 출력
 - [ ] 기능선택 입력 

## 페어 매칭 입력
 -[ ] 과정 레벨 미션 출력
 - [ ] 과정 레벨 미션 입력

## 페어 매칭 기능
 - [ ] 과목 페어 매칭 시작
 - [ ] readme 에 있는것처럼 크루 목록 가져옴
 - [ ] 매칭
 - [ ] 같은레벨의 다른 과목의 매칭목록 조회
 - [ ] 같은 페어가 있으면 롤백
 - [ ] 안내문구를 출력 후 아니오시 다시 선택 , 예 일시 다시 진행 

## 페어 조회 기능
 - [ ] 과정 레벨 미션 선택입력창
 - [ ] 매칭 이력이 없으면 에러
 - [ ] 있으면 매칭 결과 출력

## 페어 초기화
 - [ ] 과목객체를 전체 조회하면서 페어목록을 전부 초기화한다.
