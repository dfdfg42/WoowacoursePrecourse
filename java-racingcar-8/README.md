# java-racingcar-precourse

### 도메인 로직
- [x] `Car` 객체를 생성할 수 있다. (이름과 현재 위치를 상태로 가짐)
- [x] `Car`는 0-9 사이의 무작위 값이 4 이상일 경우 1칸 전진(move)할 수 있다.
- [x] `Car`는 0-9 사이의 무작위 값이 3 이하일 경우 멈춘다.
- [x] `Car`의 현재 위치를 가져올 수 있다.

### 게임 관리 로직
- [ ] 쉼표(`,`)로 구분된 자동차 이름 문자열을 `Car` 객체 리스트로 변환한다.
- [ ] 1회(라운드) 실행 시, 모든 `Car` 객체가 전진 또는 정지 로직을 수행한다.
- [ ] 가장 멀리 전진한 자동차(들)를 찾아 우승자로 선정한다.

### 입력 및 유효성 검증
- [ ] (입력) 경주할 자동차 이름 문자열을 `Console`로부터 입력받는다.
- [ ] (입력) 시도할 횟수 문자열을 `Console`로부터 입력받는다.
- [x] (검증) 자동차 이름이 5자를 초과하는 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (검증) 자동차 이름에 공백이 포함되거나 이름이 없는 경우 `IllegalArgumentException`을 발생시킨다.
- [ ] (검증) 시도할 횟수가 숫자가 아니거나 1 미만의 값일 경우 `IllegalArgumentException`을 발생시킨다.

### 출력 (View)
- [ ] "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 프롬프트를 출력한다.
- [ ] "시도할 횟수는 몇 회인가요?" 프롬프트를 출력한다.
- [ ] "실행 결과" 헤더를 출력한다.
- [ ] 각 라운드(차수)별로 모든 자동차의 이름과 현재 위치(`-` 기호)를 출력한다.
- [ ] 최종 우승자를 "최종 우승자 : [이름]" 형식으로 출력한다. (공동 우승 시 쉼표로 구분)
