# java-planetlotto-precourse

### 1. 도메인 Lotto 클래스
- [x] 'Lotto' 생성자의 'validate()' 메서드에 중복 숫자 검증 기능 추가.
- [x] 'Lotto' 생성자의 'validate()' 메서드에 숫자 범위 검증 기능 추가.
- [x] 'Lotto' 번호를 오름차순으로 정렬하여 반환하는 기능 추가
- [x] 'Lotto' 번호가 다른 'Lotto'(당첨 번호) 와 일치하는 숫자 개수를 반환하는 기능 구현
- [x] 'Lotto' 번호가 보너스 번호를 포함하는지 확인하는 기능 구현
- [x] 'Winning Lotto ' 테스트 , 객체 구현 

### 2.도메인 'Rank' Enum(당첨 등수)
- [x] 'Enum' 을 사용하여 1등부터 5등, 꽝 까지의 당첨 기준 과 상금을 정의
- [x] 일치 개수와 보너스 일치 여부를 입력받아 해당하는 'Rank' 를 반환하는 static 메서드를 구현한다.

### 3.도메인: 'Statistics'(당첨 통계)
- [x] 구매한 'List<Lotto>' 와 당첨 번호/보너스 번호를 비교하여 당첨 통계 ('Map<Rank,Integer>') 를 생성한다

### 4. 서비스: 로또 발매기
- [x] 로또 1개를 자동 생성한다.
- [x] 구매 금액 만큼 로또를 발매하여 List<Lotto> 를 반환한다.

### 5. 입력 및 검증
- [x] (입력) 로또구입 금액을 입력받는다.
- [x] (검증) 구입 금액이 500 단위가 아니거나 500 미만이거나 숫자가 아닌경우 `IllegalArgumentException`을 발생시킨다.
- [x] (입력) 당첨 번호 5개를 쉼표(,)로 구분하여 'Console'로부터 입력받는다.
- [x] (검증) 당첨 번호가 5개가 아니거나 , 1~30범위를 벗어나거나, 숫자가 아닌경우 `IllegalArgumentException`을 발생시킨다. (`Lotto` 클래스 재활용)
- [x] (입력) 보너스 번호 1개를 입력받는다.
- [x] (검증) 보너스 번호가 1~30번호를 벗어나거나 , 숫자가 아닌경우 `IllegalArgumentException`을 발생시킨다.
- [x] (검증) 보너스 번호가 당첨번호 5개와 중복되는 경우 `IllegalArgumentException`을 발생시킨다.
- [x] 예외 발생 시 [ERROR] 메시지를 출력하고 해당부분부터 다시 받는다.

### 6. 출력
- [x] 입력프롬프트를 출력한다.
- [ ] 구매한 로또 개수를 출력한다
- [ ] 구매한 로또 번호 전체를 오름차순으로 정렬하려 출력한다.
- [ ] 당첨와 구분선을 출력한다.
- [ ] 1등부터 5등 순서로 당첨 내역을 출력한다.
