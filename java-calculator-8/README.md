# java-calculator-precourse


- [x] 빈 문자열 또는 null 값을 입력할 경우 0을 반환하는 기능
- [x] 쉼표(,)를 구분자로 가지는 문자열을 입력할 경우, 각 숫자의 합을 반환하는 기능 (예: "1,2" -> 3)
- [x] 쉼표(,) 외에 콜론(:)도 구분자로 사용 가능한 기능 (예: "1,2:3" -> 6)
- [x] `//`와 `\n` 문자 사이에 커스텀 구분자를 지정할 수 있는 기능 (예: "//;\n1;2;3" -> 6)
- [x] 문자열 계산기에 음수 또는 숫자 이외의 값을 입력할 경우 `IllegalArgumentException`을 발생시키는 기능
- [x] `Console`을 통해 사용자로부터 덧셈할 문자열을 입력받는 기능
- [x] `Console`을 통해 계산 결과를 "결과 : [값]" 형식으로 출력하는 기능
